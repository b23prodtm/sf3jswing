This is THE GAME main package.


Every class in this package is defining the various aspects of a game, written in Java. The global structure can be outfitted of this package, made of interfaces and listeners.

Initially, the program was a Pong game. Multi-player layout and server-side logic was implemented by then. Afterwards, the idea was to make a full game engine for its final purpose largely overwhelmed the Pong initial statements. It turns out into a project similar to the old M.U.G.E.N, because it's a battle game engine too, though none of the code was (im)ported from this latter engine. Besides coding, publishing an gaming Applet was the first idea of this project. Java has proven since the beggining of the developement, that open source is very attractive, for a great density of documentations and libraries is freely available, which everybody can recognize it as a powerful platform for efficient software publishing.


LWJGL api has slightly improved the Graphics and Sound and whose high-end performance capabilities gave a great hope of completion of this project.
