1.    Raccourcis (toc)

Ctrl/Command + N

Nouvel album :

ajoute une nouvelle entrée dans “albums”

Ctrl/Command + O

Ouvrir :

Ouvre un fichier image

Ctrl/Command + S

Enregistrer :

Enregistre la sélection courante

Ctrl/Command + Shift/Alt + S

Enregistrer sous :

Enregistre la sélection courante sous un nouveau nom

Ctrl/Command + P

Imprimer :

Imprime la sélection

Ctrl/Command + Q

Quitter :

Quitte l'application

Ctrl/Command + Z

Annuler :

Annule la dernière modification sur la sélection

Ctrl/Command + Shift/Alt + Z

Tout annuler :

Annule tous les changements effectué sur la sélection

Ctrl/Command + C

Copier :

Copie la sélection vers le presse-papier

Ctrl/Command + A

Tout sélectionner :

Sélectionne toutes les images de l'album courant

Ctrl/Command + R

Actualiser :

Actualise le navigateur

Ctrl/Command + Supprimer

Supprimer de l'album :

Supprime la sélection de l'album

Ctrl/Command + E

Exporter :

Exporte l'album vers un fichier .imc

Ctrl/Command + I

Importer :

Importe un fichier .imc externe comme album





Ctrl/Command + 2
