1.    Verknüpfungen (toc)

Ctrl/Command + N

Neues Album

fügt ein neues Album ins “Alben” hinzu

Ctrl/Command + O

Öffnen :

ein Datei öffnen

Ctrl/Command + S

Speichern :

Speichert den Auswahl

Ctrl/Command + Shift/Alt + S

Speichern an

Speichert den Auswahl an einen neuen Name

Ctrl/Command + P

Drucken :

Druckt den Auswahl

Ctrl/Command + Q

Verlassen :

Schliesst das Programm ab

Ctrl/Command + Z

Zurück :

Bricht die letzte ausgewählte Änderung

Ctrl/Command + Shift/Alt + Z

Alles zurück :

Alle letzte Ändeungen abbrechen

Ctrl/Command + C

Kopieren :

Kopiert den Auswahl in s Systemclipboard

Ctrl/Command + A

Alles auswählen :

Wählt alle Bilder im Album aus

Ctrl/Command + R

Aktualisieren :

Aktulisiert das Browser

Ctrl/Command + Delete

Aus dem Album entfernen :

Entfernt den Auswahl aus dem Album

Ctrl/Command + E

Exportieren :

Exportiert das ausgewähltes Album in ein externales .imc Datei

Ctrl/Command + I

Importieren :

Importiert ein externales .imc Album Datei in das Browser





Ctrl/Command + 2

Exportieren nach Picasa™ :

Exportiert den Auswahl nach Picasa™

Ctrl/Command + Shift/Alt + 1

Importieren aus Facebook® :

Importiert ein externales Facebook® Album in das Browser

F1

Schnelle Anleitung:
