1.    Shortcuts (toc)

Ctrl/Command + N

New album :

adds a new album entry in “albums”

Ctrl/Command + O

Open :

Opens a new image file

Ctrl/Command + S

Save :

Saves the current selection

Ctrl/Command + Shift/Alt + S

Save As :

Saves the current selection with new file names

Ctrl/Command + P

Print :

Prints the current selection

Ctrl/Command + Q

Quit :

Exits the application

Ctrl/Command + Z

Undo :

Cancels the last modification on the current selection

Ctrl/Command + Shift/Alt + Z

Undo All :

Revert all changes that have been made on the current selection

Ctrl/Command + C

Copy to clipboard :

Copies the current selection to the system clipboard

Ctrl/Command + A

Select All :

Selects all pictures in the current album

Ctrl/Command + R

Refresh :

Refreshes the browser

Ctrl/Command + Delete

Remove from album :

Deletes the current selection from the current album

Ctrl/Command + E

Export :

Exports the current album to an external .imc file

Ctrl/Command + I

Import :

Imports an external .imc album file into the browser





Ctrl/Command + 2

Export to Picasa™ :

Exports the current selection to Picasa™

Ctrl/Command + Shift/Alt + 1

Import from Facebook® :

Imports an external Facebook® album into the browser

F1

Quick guide :

Displays this quick reference guide

 Ctrl/Command + Shift/Alt + 2

Import from Picasa™ :

Imports an external Picasa™ album into the browser
